August Ecommerce Platform

August Ecommerce is a full-stack skincare and beauty marketplace that provides users with a seamless online shopping experience. Customers can browse products, view detailed information, add items to their cart, and manage their accounts.

The application includes user registration, login, email verification, password recovery, profile management, and product publishing with image uploads. It also features responsive pages, form validation, theme switching, and user-friendly notifications.

The platform was built with React and Vite on the frontend, supported by a Node.js, Express, and MongoDB backend. It uses JWT and bcrypt for authentication, Cloudinary for image storage, and Brevo for transactional emails.

This project strengthened my full-stack development skills, particularly in React, API integration, state management, and responsive UI design.
